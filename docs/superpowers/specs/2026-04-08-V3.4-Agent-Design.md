## 3. 核心模块设计

### 3.1 RiskScore Engine

**位置**: `backend/app/services/risk_score_engine.py`

**核心逻辑**:

```python
class RiskScoreEngine:
    """
    动态风险评分引擎
    连续成功次数越多，阈值越低（越激进）
    """

    def __init__(self):
        self.base_threshold = 0.7      # 基础阈值
        self.min_threshold = 0.3       # 最低阈值（最激进）
        self.consecutive_success = 0   # 连续成功计数
        self.consecutive_fail = 0      # 连续失败计数
        self.risk_history = []         # 历史风险记录

    def calculate_threshold(self) -> float:
        """根据连续成功次数动态计算阈值"""
        # 每连续成功3次，阈值降低0.1
        reduction = (self.consecutive_success // 3) * 0.1
        return max(self.base_threshold - reduction, self.min_threshold)

    def calculate_risk_score(self, context: dict) -> float:
        """
        计算当前操作的风险得分 (0.0 ~ 1.0)
        得分越高越危险
        """
        score = 0.0

        # 因素1: 页面类型 (0-0.3)
        page_type = context.get('page_type')
        if page_type == 'login_required': score += 0.3
        elif page_type == 'captcha': score += 0.25
        elif page_type == 'popup': score += 0.15
        elif page_type == 'job_detail': score += 0.1

        # 因素2: 连续失败次数 (0-0.3)
        consecutive_fail = context.get('consecutive_fail', 0)
        score += min(consecutive_fail * 0.1, 0.3)

        # 因素3: 短时间内操作频率 (0-0.2)
        recent_ops = context.get('recent_operations', 0)
        if recent_ops > 10: score += 0.2
        elif recent_ops > 5: score += 0.1

        # 因素4: 异常关键词检测 (0-0.2)
        if context.get('has_error_keywords'): score += 0.2

        return min(score, 1.0)

    def record_result(self, success: bool):
        """记录结果，更新连续成功/失败计数"""
        if success:
            self.consecutive_success += 1
            self.consecutive_fail = 0
        else:
            self.consecutive_fail += 1
            self.consecutive_success = 0
```

**RiskScore等级**:

| 得分 | 等级 | 颜色 | 行动 |
|------|------|------|------|
| 0.0-0.3 | 低风险 | 绿 | 自动处理，无需干预 |
| 0.3-0.6 | 中风险 | 黄 | RecoveryEngine尝试处理 |
| 0.6-1.0 | 高风险 | 红 | 暂停，等待人工确认 |

### 3.2 Job Queue Engine

**位置**: `backend/app/services/job_queue.py`

**队列状态流转**:

```
pending → running → completed (成功)
                    → failed (失败，可重试)
                    → skipped (用户跳过)
                    → relocated (重定位到其他职位)
```

```python
class JobQueue:

    def update_status(self, item_id, status, **kwargs)
```

### 3.3 Stealth Mode

**位置**: `playwright/src/services/stealth_service.py` (新建)

**实现层次**:

```python
class StealthConfig:
    """Stealth模式配置"""

    # 1. WebDriver属性移除
    remove_webdriver = True

    # 2. User-Agent随机化
    user_agents = [
        'Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36...',
        'Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36...',
    ]

    # 3. 浏览器指纹随机化
    canvas_randomization = True
    webgl_randomization = True
    audio_randomization = True
    timezone_randomization = True
    language_randomization = True

    # 4. 行为模拟
    human_scroll = True
    human_mouse_movement = True
    human_click_timing = True
    random_delay_between_actions = (1, 3)  # 秒


class HumanBehaviorSimulator:
    """人类行为模拟器"""

    async def human_scroll(self, page):
        """模拟人类滚动: 不是直线，而是有停顿的曲线"""
        for _ in range(random.randint(3, 6)):
            await page.evaluate(f"""
                window.scrollBy({random.randint(100, 300)}, {random.randint(200, 500)})
            """)
            await asyncio.sleep(random.uniform(0.5, 1.5))

    async def human_mouse_move(self, page, target_x, target_y):
        """模拟人类鼠标移动: 曲线路径，带抖动"""
        steps = random.randint(8, 15)
        for i in range(steps):
            ratio = i / steps
            x = target_x * ratio + random.uniform(-10, 10)
            y = target_y * ratio + random.uniform(-10, 10)
            await page.mouse.move(x, y)
            await asyncio.sleep(random.uniform(0.02, 0.08))

    async def human_click(self, page, x, y):
        """人类点击: 移动到目标 + 小停顿 + 点击"""
        await self.human_mouse_move(page, x, y)
        await asyncio.sleep(random.uniform(0.1, 0.3))
        await page.mouse.click(x, y)
```

### 3.4 搜索重定位

**位置**: `playwright/src/services/embedding_service.py` (扩展)

**流程**:

```
原始URL失效
    ↓
提取 job_title + company
    ↓
搜索前20条结果
    ↓
Embedding匹配度计算
    ↓
选择相似度 > 阈值(0.8)的职位
    ↓
自动投递 + 记录重定位信息
    ↓
发送SSE事件通知前端
```
